# Pending Decision Approval Workflow

## Original Request

Add a rule to `AGENTS.md`: when a change is worth mentioning in `DECISIONS.md`, create a decision with pending status and wait for the user to accept the decision before continuing its development.

## Implementation

Added a Decision Records section to `AGENTS.md`. It requires significant decisions to be recorded with **Pending** status and explicitly accepted by the user before dependent development continues.
